Oak Brook Park District / Workplace application

Digital Membership Cards

I built a staff app for importing member records and issuing digital passes that members can add to Apple Wallet or Google Wallet.

  • Power Apps, Power Automate, SharePoint, Azure
Read case study: Digital Membership Cards
The challenge
The previous pass delivery process could be interrupted by email delivery problems. Staff also needed a way to fix individual import errors without holding up an entire batch.
What I built
I connected a Power Apps interface to SharePoint records and Power Automate workflows, with Azure supporting pass generation. The import workflow checks for missing emails, missing pass numbers, and duplicate records. Valid records can proceed while staff review and correct flagged rows.
How staff use it
Staff can create and resend passes. Each barcode uses the existing membership number. Regular memberships have no set expiry, while seasonal passes use a manager-set season end date.

Oak Brook Park District / Workplace application

Photo Library Admin Dashboard

I built an internal dashboard for a SharePoint photo and video library, with automation that keeps file metadata accurate when folders move.

  • Power Apps, Power Automate, SharePoint
Read case study: Photo Library Admin Dashboard
The challenge
When staff moved a folder, the files moved too, but metadata based on the files’ old location could stay behind. That made the library harder to organize and maintain.
What I built
I added automation to update location-related metadata on the files inside a moved SharePoint folder, rather than requiring staff to edit each item. The dashboard gives administrators one place to manage photos and videos.
Why it matters
Staff can reorganize the library without leaving files associated with the wrong location. The dashboard, SharePoint library, and automation are separate pieces, so changes to the interface don’t have to change the underlying filing rules.
