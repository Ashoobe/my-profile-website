Oak Brook Park District / Membership services

Digital Membership Cards

I built a staff app that takes an ActiveNet export through validation and email delivery, so members can add their cards to Apple Wallet or Google Wallet.

  • Power Apps, Power Automate, SharePoint Online, Node.js, Azure Functions
Read case study: Digital Membership Cards
The challenge
When a member called about a missing card, staff needed to know whether the record had been imported, whether a card had been created, and what happened to the email.
Data and workflow
I organized the data across 15 SharePoint lists and a document library. Each upload has a batch ID, and each row gets a validation result. Staff can correct a missing pass number or invalid email without holding back valid rows. A member ID links the record to its passes and delivery attempts.
Wallet and delivery integration
Node.js functions parse CSV and Excel exports, generate signed Apple Wallet passes and Google Wallet cards, and encode the existing membership number as a Code 128 barcode. A separate delivery check is designed to use Exchange message trace to distinguish a send attempt from delivery to the receiving mail server.
How staff use it
Staff can search by pass number, review and correct imports, and resend cards. Managers can update the card design and set the season end date for Splash Island passes. Oak Brook memberships can be issued without an expiration date. The front desk can keep scanning the existing membership number.

Oak Brook Park District / Marketing and media

Photo Library Admin Dashboard

I built a SharePoint-backed dashboard for uploading, organizing, and reviewing district photos and videos.

  • Power Apps, Power Automate, SharePoint Online
Read case study: Photo Library Admin Dashboard
The challenge
Large videos could appear in the library before they finished uploading. Moving a folder could also leave its files named for their old location.
Data and review
I separated the media library from lists that track upload requests, approved destinations, and dashboard summaries. I kept the original filename alongside the managed name, so reviewers can trace an upload and compare a suspected duplicate with the earlier file before choosing which copy to keep.
Automation
Power Automate checks the destination and uses file size, modification time, and checkout status to assess whether a video is ready. File naming uses the folder path and SharePoint file ID. A scheduled flow updates affected filenames in place after a folder moves, and a separate flow calculates dashboard totals in batches.
What changed
Staff can reorganize collections without renaming files one by one. Reviewers can inspect potentially duplicate uploads before anything is removed.

Custodial Operations App

I built a bilingual checklist app that gives custodians a tablet-friendly view of their work and managers a separate place to plan and review it.

  • Power Apps, Power Fx, SharePoint Online, Microsoft Translator
Read case study: Custodial Operations App
The challenge
A manager needs to create checklists and assign shifts by site. A custodian on an iPad needs to open an assignment, answer a question, take a photo, and move on.

SharePoint stores checklist templates and versions, assignments, submissions, and answers. I tied each photo to the answer it documents. A manager can trace it back to the checklist item, submission, and assignment without relying on the filename.

Oak Brook Park District / Facilities maintenance

Maintenance Hub

I built an app that takes a facility request into the technician’s workflow while keeping the location, photos, comments, and status history together.

  • Power Apps, SharePoint Online, Power Automate, Microsoft 365 Outlook
Read case study: Maintenance Hub
Data design
A ticket ID connects the request to its comments and status changes. The Maintenance Hub and Custodial app use the same facility directory. I kept recurring service plans separate from individual service records so the team can see what was planned and what was completed.
Visibility and workflow

Oak Brook Park District / Tennis Center operations

FRIDAY: Team Assignments and Recurring Work

I built an app that gives employees a personal view of their assignments and lets managers track recurring work without losing the history of each task.

  • Power Apps, Power Automate, SharePoint Online
Read case study: FRIDAY: Team Assignments and Recurring Work
Data design
I separated a recurring task series from its individual tasks. Each task has its own ID and keeps its assignees, checklist, messages, issues, activity, and attachments. Team membership is stored separately so managers can assign work to people on the selected team.
Automation
The app uses Power Automate to load assignments, save progress, manage teams, and export reports. Other flows handle reminders, notifications, and request routing.
How staff use it
An employee sees what to do next, even when a task has multiple assignees. A manager can open an individual occurrence to see who owned it, what was completed, and what needs follow-up.
